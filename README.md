# 📝 Python CLI To-Do List Application

A simple, interactive, and fast Command-Line Interface (CLI) To-Do List application built with pure Python.

## 📌 Features
- **Inspect List:** View all stored tasks with clean numbered indexing (`1..N`).
- **Add Tasks:** Append new activities dynamically to your interactive list.
- **Remove Tasks:** Delete specific tasks from the list when completed.
- **Interactive Menu Loop:** Continuous user workflow until explicitly exiting.

---

## 🛠️ Tech Stack & Requirements
- **Language:** Python 3.x
- **Dependencies:** None (Uses Python Standard Library only)
